# برنامج إدارة المتجر

برنامج بسيط لإدارة منتجات متجر من خلال نافذة Terminal، باستخدام أساسيات
البرمجة كائنية التوجه (OOP) وملف JSON لحفظ البيانات. لا يحتاج إلى إعداد
قاعدة بيانات.

## المتطلبات

- Windows 10
- Python 3 مثبت على الجهاز ومضاف إلى `PATH`
- المكتبات الموجودة في `requirements.txt` لتشكيل العربية في الطرفية

للتحقق من تثبيت Python، افتح Command Prompt أو Terminal واكتب:

```text
python --version
```

إذا لم يعمل الأمر، جرّب:

```text
py --version
```

## تشغيل نسخة Terminal

1. افتح مجلد `PythonStore` في VS Code.
2. افتح Terminal من القائمة **Terminal > New Terminal**.
3. ثبّت المكتبات المطلوبة:

```text
python -m pip install -r requirements.txt
```

4. شغّل البرنامج بأحد الأمرين:

```text
python main.py
```

إذا كان أمر `python` غير متاح، استخدم `py` لتثبيت المتطلبات وتشغيل البرنامج:

```text
py -m pip install -r requirements.txt
py main.py
```

5. اختر رقم العملية من القائمة واتبع التعليمات.

يضبط البرنامج ترميز الطرفية إلى UTF-8 ويشكّل الحروف العربية عند عرضها.
إذا استمرت مشكلة العرض، استخدم Windows Terminal أو الطرفية المدمجة في VS Code
وتأكد من اختيار خط يدعم العربية.

## تشغيل الواجهة الرسومية في المتصفح

تستخدم الواجهة Streamlit، وتشارك أصناف المخزون والحفظ نفسها مع نسخة Terminal.
من داخل مجلد `PythonStore` افتح Terminal ونفّذ:

```text
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

افتح عنوان المتصفح الذي يظهر في Terminal، وغالبًا يكون:
`http://localhost:8501`.

إذا كان أمر `python` غير متاح، استخدم:

```text
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

للإيقاف، ارجع إلى Terminal واضغط `Ctrl+C`.

## حفظ البيانات

يحفظ البرنامج المنتجات تلقائيًا في `products.json` بعد الإضافة أو التعديل
أو البيع. عند تشغيل البرنامج مرة أخرى، يقرأ المنتجات من الملف. لا تحذف هذا
الملف إذا كنت تريد الاحتفاظ ببياناتك.

## الملفات

- `main.py`: يعرض قائمة الخيارات ويستقبل إدخال المستخدم ويربط أجزاء البرنامج.
- `app.py`: واجهة Streamlit العربية، وتستدعي `Inventory` و`ProductStorage`
  لتنفيذ العمليات نفسها التي تستخدمها نسخة Terminal.
- `product.py`: يحتوي على الصنف `Product` لتمثيل منتج وتهيئة بياناته للحفظ.
- `inventory.py`: يحتوي على الصنف `Inventory` لإضافة المنتجات والبحث عنها
  وتعديلها وتنفيذ البيع.
- `storage.py`: يحتوي على الصنف `ProductStorage` لقراءة المنتجات من ملف JSON
  وحفظها.
- `terminal_display.py`: يضبط UTF-8 ويشكّل النص العربي قبل عرضه في الطرفية.
- `requirements.txt`: يحدد المكتبات اللازمة لعرض العربية بشكل صحيح.
- `products.json`: ملف البيانات الذي يحتفظ به البرنامج.

## ملاحظات الاستخدام

- لكل منتج رقم يُنشأ تلقائيًا عند إضافته؛ استخدمه عند التعديل والبيع.
- يمكن البحث بكتابة الاسم كاملًا أو جزء منه.
- يجب أن يكون السعر أكبر من صفر، والكمية صفرًا أو أكبر.
- لا يمكن بيع كمية أكبر من الكمية الموجودة في المخزون.
